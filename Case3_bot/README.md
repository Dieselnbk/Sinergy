# Кейс-задача № 3 — Чат-бот справочной службы Университета «Синергия»

Бот отвечает на типовые вопросы абитуриентов и студентов: поступление, формы обучения, личный кабинет, практика, стоимость, контакты, расписание.

**Технологии:** Python 3, NLTK (`SnowballStemmer` для русского языка).

**Алгоритм:** токенизация → стемминг → подсчёт совпадений с ключевыми словами по 11 интентам → выбор интента с максимальным счётом; если совпадений нет — подсказка пользователю.

## Запуск
```bash
pip install -r requirements.txt
python bot.py        # диалог в консоли
python test_bot.py   # тесты точности и скорости
```

## Пример диалога
```
Вы: Привет
Бот: Привет! Я помощник Университета «Синергия»...
Вы: Какие документы нужны для поступления?
Бот: Для поступления нужны: паспорт, документ об образовании...
Вы: Какая погода?
Бот: Извините, я не понял вопрос. Попробуйте переформулировать...
```
