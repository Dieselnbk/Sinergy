# Кейс-задача № 3 — Чат-бот справочной службы Университета «Синергия»

## Задание

Адаптируйте задание под организацию, на базе которой вы проходите практику.

Создание простого чат-бота. Задача состоит в том, чтобы создать простой чат-бот, который может отвечать на простые вопросы пользователей. Бот должен уметь распознавать ключевые слова и предлагать соответствующие ответы.

- **Определение ключевых слов и ответов:** первым шагом в создании чат-бота является определение ключевых слов и соответствующих ответов. Это могут быть простые вопросы и ответы, например:
  - «Привет» — «Привет! Как могу помочь?»
  - «Какая погода?» — «Сейчас посмотрю... Идет дождь.»
- **Написание кода для распознавания ключевых слов:** необходимо написать код, который будет распознавать эти ключевые слова. В Python это можно сделать с помощью библиотеки NLTK (Natural Language Toolkit) или spaCy.
- **Написание кода для предоставления ответов:** после того, как код распознает ключевые слова, он должен предоставить соответствующие ответы. Это можно сделать с помощью простой функции, которая будет вызывать соответствующие ответы в зависимости от распознанного ключевого слова.
- **Тестирование и отладка:** после написания кода необходимо его протестировать и отладить. Это может включать в себя проверку работы с различными типами вопросов и ответов, а также исправление ошибок, если таковые имеются.
- **Развертывание и использование:** после того, как чат-бот будет полностью протестирован и отлажен, его можно развернуть и использовать. Это может включать в себя интеграцию с мессенджерами, такими как Telegram или WhatsApp, или создание веб-интерфейса для общения с ботом.

Ответом на задачу будет ссылка на репозиторий GitHub, где хранится Ваша программа, или иным удобным для Вас способом.

## Ответ

Бот отвечает на типовые вопросы абитуриентов и студентов: поступление, формы обучения, личный кабинет, практика, стоимость, контакты, расписание. Кроме готовых ответов, бот умеет сообщать **текущую погоду** в выбранном городе: данные он запрашивает в интернете в момент вопроса.

**Технологии:** Python 3, NLTK (`SnowballStemmer` для русского языка). Запросы в интернет выполняются стандартной библиотекой (`urllib`, `json`), дополнительных пакетов не нужно.

**Алгоритм:** токенизация → стемминг → подсчёт совпадений с ключевыми словами по 12 интентам → выбор интента с максимальным счётом → для большинства тем готовый ответ, для погоды — запрос к сервису wttr.in; если совпадений нет — подсказка пользователю.

## Ответы по данным с сайтов

Часть вопросов бот закрывает не готовым текстом, а данными из интернета. Пока реализована погода через сервис wttr.in (`web_sources.py`): один запрос `https://wttr.in/<город>?format=j1&lang=ru`, ключ и регистрация не нужны.

- город берётся из вопроса (Москва, Санкт-Петербург, Казань, Екатеринбург, Сочи и др.), если города нет — Москва;
- «сейчас»: температура, ощущаемая температура, описание, ветер, влажность, давление; «сегодня» — минимум и максимум; «завтра» — прогноз на следующий день;
- ответы кэшируются на 10 минут, при сбое сети или неожиданном ответе бот выдаёт понятное сообщение;
- загрузка отделена от разбора, поэтому тесты работают без интернета на сохранённом ответе сервиса (`tests_data/`).

Новый источник добавляется отдельной функцией в `web_sources.py` и новым интентом в `INTENTS`.

## Запуск
```bash
pip install -r requirements.txt
python bot.py        # диалог в консоли
python test_bot.py   # тесты точности и скорости
```

## Пример диалога
```
Вы: Привет
Бот: Привет! Я помощник Университета «Синергия»...
Вы: Какие документы нужны для поступления?
Бот: Для поступления нужны: паспорт, документ об образовании...
Вы: Какая погода?
Бот: Москва, сейчас: +15 °C (по ощущению +11), солнечно, ветер 3 м/с, влажность 44 %, давление 774 мм рт. ст. Сегодня от +8 до +15 °C. (Источник: wttr.in) Чтобы узнать погоду в другом городе, добавьте его в вопрос.
Вы: Погода завтра в Казани
Бот: Казань, завтра: от +9 до +15 °C, солнечно. (Источник: wttr.in)
Вы: Расскажи анекдот
Бот: Извините, я не понял вопрос. Попробуйте переформулировать или спросить про: документы, формы обучения, личный кабинет, практику, стоимость, контакты, расписание.
```

Значения погоды в примере условные, при запуске бот показывает актуальные данные.
