# Кейс-задача № 4 — Аналитический обзор чат-бота (кейс 3)

**Тестирование:** 36 фраз (простые, с иной формулировкой, вне тематики) — `Case3_bot/test_bot.py`.
Верно распознано 35 → **точность 97,2 %**. Среднее время ответа 0,26 мс, максимум 0,54 мс.

- **Функциональность:** распознаёт 11 тем и отвечает по ним, на неизвестные вопросы выдаёт подсказку.
- **Точность распознавания:** 97,2 %. Единственная ошибка: «Во сколько работает университет» принято за вопрос о стоимости из-за слова «сколько».
- **Качество ответов:** информативные и краткие; часть данных (цены) отсылает на сайт.
- **Интерактивность:** низкая — нет контекста и уточняющих вопросов.
- **Скорость ответа:** отличная, менее 1 мс.
- **Удобство использования:** консольный интерфейс, нет кнопок и меню.
- **Возможности расширения:** высокие — новая тема добавляется одной записью в словарь `INTENTS`.
- **Эффективность разработки:** быстрая (несколько часов), только Python и NLTK, без обучения моделей.
- **Техническая реализация:** правила + стемминг; не нужны обучающие данные, поведение прозрачно.
- **Адаптация к NLP (русский язык):** стемминг решает падежи и формы слов («документов» = «документы»), но не понимает синонимы, опечатки и смысл фразы целиком.
